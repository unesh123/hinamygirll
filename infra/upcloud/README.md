# UpCloud staging definitions (offline)

**Provisioning is blocked** unless both are set by the owner:

```text
HINAA_ALLOW_UPCLOUD_PROVISIONING=1
HINAA_UPCLOUD_PROVISIONING_CONFIRM=I_AUTHORIZE_STAGING_RESOURCES
```
