## 3. How to Execute Training via API or Script

### 3.1 Via FastAPI Endpoint
```bash
curl -X POST "http://localhost:8000/api/neural-lab/train" \
  -H "Content-Type: application/json" \
  -d '{
    "base_model_id": "Qwen/Qwen2.5-1.5B-Instruct",
    "dataset_name": "hinaa_curated_v1",
    "epochs": 3,
    "batch_size": 2,
    "learning_rate": 0.0002,
    "lora_r": 16,
    "lora_alpha": 32,
    "use_4bit": true
  }'
```

### 3.2 Via Python Subsystem
```python
from hinaa_api.neural_lab.training.pipeline import run_training_pipeline
from hinaa_api.neural_lab.training.lora_config import TrainingJobRequest

job = TrainingJobRequest(
    base_model_id="Qwen/Qwen2.5-1.5B-Instruct",
    dataset_name="hinaa_curated_v1",
    epochs=3,
    batch_size=2,
    learning_rate=2e-4,
    lora_r=16,
    lora_alpha=32,
    use_4bit=True
)
result = run_training_pipeline(job)
print(f"Training status: {result.status}, Final Loss: {result.metrics.get('final_loss')}")
```

## 4. Exporting to Ollama via Modelfile

HINAA Neural Lab automatically creates the Ollama `Modelfile` for any trained adapter:

```dockerfile
# Generated by HINAA Neural Lab Adapter Manager
FROM qwen2.5:1.5b
ADAPTER ./adapters/hinaa-core-v1.0.0/adapter_model.bin
PARAMETER temperature 0.7
PARAMETER top_p 0.9
PARAMETER stop "<|im_end|>"
SYSTEM """
You are Hina, an autonomous, intelligent AI companion and digital operator.
You speak with genuine warmth, technical rigor, and zero repetitive filler.
When executing actions, you use verified tools and never claim unperformed actions.
"""
```

To register and serve locally in Ollama:
```bash
ollama create hinaa-core-v1 -f ./adapters/hinaa-core-v1.0.0/Modelfile
ollama run hinaa-core-v1
```

Once registered, Hina's model router automatically dispatches low-latency requests to `http://localhost:11434/api/generate` with zero cloud bandwidth and zero API cost.
