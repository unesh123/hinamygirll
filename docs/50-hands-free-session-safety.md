# 50 — Hands-free session safety

## Meaning of hands-free

After the user **explicitly** starts a live session and grants microphone
permission, HINAA can listen → detect end-of-turn → answer → speak → return to
listening without a button on every turn.

Hands-free is **not** hidden always-on surveillance.

## Hard rules

- Mic starts only after user action + browser permission.
- UI shows active listening clearly.
- Pause listening and End session are always available.
- Capture stops when the session ends.
- No auto-start on page load.
- Raw audio is not retained by default.
- Manual text and push-to-talk remain accessibility fallbacks.

## Personality bounds

Warm, playful, caring, professional when needed — never sexual, jealous,
possessive, conscious-claiming, or emotionally coercive. Personality never
overrides safety, privacy, honesty, or validation.
