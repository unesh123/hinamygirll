# Prompt Engineering Expert

## Best Practices
1. **XML Scaffolding**: Use <context>, <rules>, <input>, <instructions> to structure complex instructions.
2. **Chain-of-Thought**: Mandate internal reasoning before concluding.
3. **Negative Constraints**: Pair negative rules with positive alternatives.
4. **Evaluation & Calibration**: Iteratively test edge cases and refine temperature/top_p.
