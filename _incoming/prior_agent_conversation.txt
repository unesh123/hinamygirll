4. How to Connect Any of These Directly into Hina

Hina’s image engine in openai_image.py is already built to accept any OpenAI-compatible image endpoint.

If you sign up for an image provider (or xKiro), you don’t need to rewrite any code in Hina. Simply add the base URL and key to your apps/api/.env.local:

bash
# Point Hina's image pipeline to any provider:
OPENAI_IMAGE_BASE_URL="https://api.runware.ai/v1"   # Or https://api.fal.ai/v1 or https://api.xkiro.com/v1
OPENAI_IMAGE_API_KEY="your_api_key_here"
OPENAI_IMAGE_MODEL="flux-schnell"                  # Or gpt-image-2.5-sunburst

Hina will automatically route image creation turns to that API while keeping your local ComfyUI GPU worker and Magnific upscaler ready as active fallbacks.
