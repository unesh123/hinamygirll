# Architecture Overview

## Core Principles
- Separation of Cognition and Environment
- Capability-scoped permissions with strict boundary validation
- Event-sourced persistent threads and context compaction
- Autonomous multi-agent coordination with recursion limits

## Key Systems
- App Server: JSON-RPC & SSE event streams
- Agent Harness: Session lifecycle, tool dispatch, and verification
- Environment: Kali Linux WSL & sandboxed shell runtimes
